# Governance
Agentic is an experimental open project initially maintained by sam1siam. It is not affiliated with or endorsed by a standards organization.

Original project code, schemas, and documentation are available under Apache-2.0. Third-party components retain their licenses. Participation does not require a paid account or permission from a central registry.

Propose changes through a GitHub issue describing the problem, current alternatives, intended client behavior, compatibility impact, and a reproducible example. Substantive changes need a pull request with normative text, schema changes where necessary, and behavioral tests. Keep decisions and dissent public.

The founding maintainer reviews changes during incubation. Invite additional maintainers after sustained substantive contributions; document appointments publicly. Once there are at least three maintainers, specification changes should require two approvals, including one from a maintainer outside the proposing organization when possible. Record conflicts of interest. Use issue discussion for disputes, then a written maintainer decision with rationale.

Draft schemas may change between explicitly versioned releases. Do not silently alter a published version's requirements. Stable 1.0 requires two independent implementations passing the same suite, evidence from real integrations, and resolution of material security and interoperability questions.

Explore an existing community or neutral project home when outside implementers are engaged. AAIF Sandbox and relevant W3C Community Groups are potential routes, not current memberships or endorsements. Well-known URI registration, if pursued, is a separate step from format standardization.

Contributors agree to respectful, technical discussion. Harassment, threats, and disclosure of private credentials or personal data are not acceptable. Maintainers may remove such content and document moderation decisions without republishing harmful details.
