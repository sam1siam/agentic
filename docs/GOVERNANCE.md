# Governance
Agentic is an open project maintained by sam1siam. Specification changes, compatibility decisions, and release notes are published in the repository.

Original project code, schemas, and documentation are available under Apache-2.0. Third-party components retain their licenses. Participation does not require a paid account or permission from a central registry.

Submit changes through a GitHub issue describing the problem, current alternatives, intended client behavior, compatibility impact, and a reproducible example. Substantive changes need a pull request with normative text, schema changes where necessary, and behavioral tests. Keep decisions and dissent public.

The founding maintainer reviews changes. Invite additional maintainers after sustained substantive contributions; document appointments publicly. Once there are at least three maintainers, specification changes should require two approvals, including one from a maintainer outside the submitting organization when possible. Record conflicts of interest. Use issue discussion for disputes, then a written maintainer decision with rationale.

Agentic uses explicit semantic versions for its profile and tools. Preserve the requirements and artifacts of published versions. A breaking profile change requires a new major version and a migration guide; compatible additions and corrections require documented versioned releases. Each release must include validation and behavioral checks appropriate to its changes. Independent implementation reports strengthen compatibility evidence and remain distinct from project-authored checks.

Explore an existing community or neutral project home when outside implementers are engaged. AAIF Sandbox and relevant W3C Community Groups are potential routes, not current memberships or endorsements. Well-known URI registration, if pursued, is a separate step from format standardization.

Contributors agree to respectful, technical discussion. Harassment, threats, and disclosure of private credentials or personal data are not acceptable. Maintainers may remove such content and document moderation decisions without republishing harmful details.
